# Points-Mode Performance Investigation — Archive

Historical archive of the points-mode multiproc investigation. The
investigation diagnosed a per-chunk obs-prep redundancy bug in the
points pipeline's parallel path, fixed it, and then re-measured —
ultimately concluding `nproc=1` always wins for points mode, after
which the multiprocessing path was removed entirely from the
production code. See git history for the full sequence (search for
"points multiproc" / "obs-prep" / "remove points multiproc" commits).

The runner scripts (`bench_utils.py`, `run_points_sweep.py`,
`run_balanced_blas_supplement.py`) were deleted alongside the
multiproc removal — only the analysers and result CSVs remain here as
a historical record. To re-run the sweep, the runners can be
recovered from git history at the relevant commits.

## Files (current contents)

| File | Role |
|---|---|
| `analyze_points_results.py` | Analyser for the original (pre-fix) investigation's CSVs. |
| `analyze_points_post_fix_results.py` | Analyser for the post-fix sweep + the balanced-BLAS supplement. |
| `results_*.csv` | Raw sweep results from each phase, preserved for reproducibility of the figures. |
| `figures/` | Heatmaps generated by the analysers. |
| `obs_csvs/` | Materialised subsampled observation CSVs used by the runners. |
| `sweep*.log` | Logs from the original sweep runs. |
